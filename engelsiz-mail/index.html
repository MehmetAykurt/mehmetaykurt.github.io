Engelsiz Mail

Accessible Gmail client add-on for the NVDA screen reader.

About the Application

Engelsiz Mail is an NVDA add-on developed to help blind and screen reader users access and manage their Gmail accounts in an accessible desktop environment.

The application uses Google OAuth 2.0 and the Gmail API. Users sign in through Google's official authorization system. Engelsiz Mail does not collect, store, or process Google account passwords.

Main Features

  • Sign in with Google OAuth 2.0.
  • List and read e-mails.
  • Send, reply to, and forward e-mails.
  • Create and manage drafts.
  • Delete and archive e-mails.
  • Create, rename, and delete archive folders using Gmail labels.
  • Use the application with keyboard and screen reader support.

Data Handling Summary

Engelsiz Mail does not operate its own server for storing user e-mails. Gmail data is accessed only through Google's Gmail API after the user grants permission. OAuth token data is stored locally on the user's computer using Windows user-account-based protection.
