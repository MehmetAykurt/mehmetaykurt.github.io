# Mehmet Aykurt - Kişisel Web Sitesi

Bu paket, GitHub Pages üzerinde So Simple Jekyll teması ile çalışacak kişisel site başlangıç dosyalarını içerir.

## Kullanım

1. Bu zip paketini açınız.
2. İçindeki tüm dosya ve klasörleri sitenize ait GitHub deposunun ana klasörüne kopyalayınız.
3. GitHub Desktop uygulamasında değişiklikleri göreceksiniz.
4. Commit mesajı olarak örneğin `So Simple site dosyaları eklendi` yazınız.
5. Commit işlemini yapınız.
6. Push işlemiyle GitHub'a gönderiniz.
7. GitHub Pages ayarında yayın kaynağının `main` dalı ve kök klasör olduğundan emin olunuz.

## Önemli düzenleme alanları

Ana sayfadaki beş şiirin ilk kıtaları `index.md` dosyasındadır.

Şiirlerin tam metinleri `_posts` klasöründeki şiir dosyalarına yazılabilir.

Telif kayıt numarası `_config.yml` dosyasında `copyright` alanında köşeli parantezle belirtilmiştir. Resmi numara alındığında bu alan değiştirilmelidir.

Domain dosyası `CNAME` adıyla pakete eklenmiştir ve içinde `mehmetaykurt.com.tr` yazmaktadır.
